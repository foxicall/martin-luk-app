# 免 SDK 的手機互動預覽

直接用瀏覽器開啟 [`index.html`](index.html)，即可操作預設 390 × 844 手機畫面。所有樣式、JavaScript 與示例資料均內嵌，離線示範完全不使用 CDN、網路報價或 Python 後端。

此頁使用 **HTML 呈現互動預覽，並不是編譯後的 Flutter**。它重現現有 Flutter App 的主要頁面與策略規則，供尚無 Flutter / Android SDK 的環境立即試用。正式 Flutter Web 預覽請依專案根目錄的說明建置，入口為 `web/phone_preview.html`。

也可以在專案根目錄啟動靜態伺服器：

```bash
bash scripts/preview_web.sh --mock --host 0.0.0.0 --port 8080
```

同一台電腦開啟 `http://127.0.0.1:8080/index.html?preview=mock`；遠端請開平台的8080埠轉送URL加上 `/index.html?preview=mock`。`preview=mock` 明確將本次開啟切換成離線示範，避免上一次保存的 API 模式阻擋預覽。一般直接開啟會讀取瀏覽器 `localStorage` 裡的上次設定；畫面頂端的「重設為離線示範」可隨時回到假資料。手機也可開啟下載到本機的 HTML 檔案（瀏覽器須允許本機 HTML 執行 JavaScript）。

## 可操作功能

- 台股 / 美股分頁，各 8 檔固定範例，股票身分與數值對應 `lib/services/candidate_repository.dart`。
- ADR 含等號篩選：台股預設 ≥ 3.5%、美股預設 ≥ 5.0%。ADR、RS、部位比率排序，6 檔一頁。
- 點擊卡片查看個股詳情、示意收盤價走勢、型態與時間戳記。
- 部位計算機修改帳戶淨值即時更新。風險預算固定 0.5%，整股向下取整，大型流動性股票持倉上限 35%，其餘 25%。
- 推薦卡片與詳情列出 PDH／ORH 觸發價、初始硬停損及固定 1R。當日低點的停損距離 > 0 且 ≤ 5% 時採用日低；超過 5% 才改用已取得的實際進場分鐘棒低點，距離須在 1.5%–3%，無效時保留觀察名單而不補造停損。無效本金會移除上一筆有效買進結果。
- 3R / 5R / 10R 目標價；3R 的 12% 減碼股數只在整股比例落於 10%–15% 時顯示。
- 深色 / 淺色外觀與設定保存；右上重新評估，以及手機頂端下拉更新。
- 「我的持股」分頁：台股與美股分開管理；新增、編輯、兩步確認刪除持股，保存於瀏覽器本機。成本、股數與初始停損皆可輸入，同一市場代碼只保留一筆，以免拆單規避曝險評估。
- 每張持股卡片顯示成本／現價、未實現損益、固定 1R、當前／已觀測高峰 R、初始／浮動硬停損、1R／2R／3R／5R／10R 具體目標、健康度與曝險比例。

## 持股診斷與調價實驗

開啟「我的持股」。台股 `2330.TW` 示例成本 1060、初始停損 1040、現價 1120，恰好為 3R，會顯示 15% 分批減碼建議；其 3R／5R／10R 目標是 1120／1160／1260。美股 `NVDA` 成本 130、初始停損 127、現價 140，為 3.33R；3R／5R／10R 目標是 139／145／160。所有價格均為假資料。

點「調整假市價」可修改現價、9／21／50 EMA 與最後收盤，診斷隨輸入立即更新，按儲存才保存報價及已觀測高峰。在 NVDA 示例中，把現價改為 135、最後收盤改為 140，關閉「此收盤已確認」，盤中跌破 9 EMA 137 不會單獨觸發全出；改為確認收盤且收盤填 135，才會產生「完整收盤跌破 9 EMA」建議。曾觀測 ≥ 2R 後，硬停損提升至成本且不會因後續回檔降低；現價觸及硬停損時優先全出，不等待收盤。

主升段設定可選 21／50 EMA；只有已觀測高峰 ≥ 3R 且勾選主升段才會生效，否則仍追蹤 9 EMA。3R／5R／10R、單部位市值嚴格超過帳戶淨值 35%，或 9 EMA 正乖離嚴格超過設定閾值（15%–20%，預設 20%），會建議強勢減碼。建議股數向下取整並檢查仍介於 10%–15%；股數過少會明確顯示無可執行整股減碼。中小股曝險超過 25% 會警示，35% 才是部位增殖的強勢減碼條件。

庫存及高峰狀態使用本機 `localStorage`，瀏覽器拒絕儲存時仍可在本工作階段操作。離線假行情與各 API 網址的已觀測高峰／浮動停損分開保存；切換來源會還原該來源紀錄，尚無紀錄則以初始停損重新觀察，假行情高峰不會觸發真實行情的保本停損。修改成本、初始停損或代碼會清除該持股在所有來源的舊觀測基準；只修改股數或追蹤設定不會清除高峰。

此頁不會自動賣出、扣除持股或產生交易委託；訊號仍存在時會持續顯示，實際減碼後應自行更新持有股數。高峰 R 只反映程式已觀測並保存的報價，不能推測程式關閉期間的歷史最高價。

風控採用 JavaScript `BigInt` 分數運算，與 Dart `StrategyEngine` 的十進位精確運算規則一致，可避免股數邊界多算 1 股。這是獨立移植的 JavaScript 實作，沒有在瀏覽器執行 Dart 引擎；`scripts/check_preview.py` 會驗證 16 檔示例與 Dart 原始資料一致，並測試停損邊界、風險與持倉上限。

## 連接真正後端

設定中填入 API 基底網址，關閉「離線示範資料」，按「儲存設定並更新」。網頁會要求：

```text
GET {API_BASE_URL}/v1/candidates?market=tw&adr_threshold=3.5
GET {API_BASE_URL}/v1/candidates?market=us&adr_threshold=5
GET {API_BASE_URL}/v1/quotes?market=tw&symbols=2330.TW,3017.TW
GET {API_BASE_URL}/v1/quotes?market=us&symbols=NVDA,TSLA
```

連線逾時、HTTP 錯誤、JSON 驗證錯誤會明確顯示；**API 失敗不會悄悄切換成假資料**。要預覽假資料請明確切回示範模式。

持股行情依每批最多 50 個代碼查詢並合併；後端的逐股錯誤會顯示於該持股卡片。API 模式停用調價功能，並拒絕來源明示為 Mock／示範的行情。只有有有效報價的持股才會提供診斷。

瀏覽器會檢查 CORS；`file://` 來源可能被 API 拒絕，建議用上述靜態伺服器，再在後端配置實際的瀏覽器來源（同機預览為 `http://127.0.0.1:8080`，遠端為實際埠轉送URL）。HTTPS 網頁不可連接被瀏覽器封鎖的 HTTP API。API 即使可連線，也只能顯示後端實際取得的股票池、資料來源與時間，不保證行情即時性。

## 提醒與資料限制

Android 通知排程是手機 App 功能，此 HTML 不要求通知權限、不執行背景排程。設定畫面會顯示台股台北時間 08:30 / 14:00、美股美東時間 08:45 / 16:30 的排程資訊。

所有示例報價、ADR、RS、訊號均為 **2026-10-13 14:00 台北時間的固定假資料**，不代表當日真實行情、推薦或全市場掃描。風險金額不包含手續費、滑價與跳空。

## 驗證

需要 Python 3 與 Node.js（不需要 Flutter）：

```bash
python3 scripts/check_preview.py
node scripts/check_preview_ui.cjs
node scripts/check_portfolio_preview.cjs
```

第一個指令檢查 HTML 內的 JavaScript 語法、示例資料是否與 Dart 同步，以及精確風控運算；實際 Flutter 編譯與元件測試仍由專案的 Flutter 檢查及 GitHub Actions 執行。

第二個指令直接執行本頁 UI handler，使用 DOM 測試替身檢查市場切換、股數更新、無效輸入、API失敗、ADR與主題。此為操作邏輯測試，並非瀏覽器排版／截圖測試。

第三個指令直接測試同一份 `portfolio-core` 與正式持股 UI handler，涵蓋門檻、保本停損、收盤確認、CRUD、行情來源隔離、舊請求、50 檔分批與本機儲存限制；同樣不代替實際瀏覽器排版驗證。
