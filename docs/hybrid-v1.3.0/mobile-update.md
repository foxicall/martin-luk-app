## 可以驗證的規則

- 美股 ADR20 ≥5%、市值 ≥1 億美元、20 日日均成交額 ≥5,000 萬美元，close > EMA21 且 EMA9 > EMA21 > EMA50。ADR 是平均 `(High / Low - 1) × 100`，不是 ATR；成交額採每日日收盤價乘成交股數的平均估算。台股獨立適配 ADR20 >3.5%。
- 盤前跳空 ≥4% 可以列掃描觀察，ORH／EP 背景嚴格要求 >4%，還需已核實催化事件及實際同時段放量。線性估計成交量不視為同時段量能證據。
- 前日漲幅前3%並放量，或20／60交易日報酬代理排名均前5%，必須有完整、同日且可比較的股票池。缺成分、單頁及滾動掃描的局部排名不算全市場百分位；並列採保守末位排名。
- PDH 使用截至觸發時的日低；距離 >3.5% 才評估有效較高的觸發5M低點。ORH 固定採第一個完整5M區間低點。回調協定所需1M／30S與訂單流目前來源不足，僅列背景。四次連續量縮需五個可比較樣本。
- 正常0.5%／回撤0.25%，可用現金、費用預留、35%／25%曝險共同限制股數。帳戶狀態預設未確認，需使用者在設定明確選擇；App 沒有扣除入出金的帳戶高水位歷史，不能自行斷定已脫離回撤。3連虧檢討、5連虧暫停須人工確認。
- 新持倉以固定初始R計算 ≥1.5R 保本建議、3R與5R各原始股數15%（股數四捨五入）、≥15%乖離額外減碼提示、日收盤跌破9EMA後次日開盤退出。費後保本仍須加入實際交易成本；不聲稱已替使用者更改訂單。可預先約定21EMA，新倉不再採50EMA例外。
